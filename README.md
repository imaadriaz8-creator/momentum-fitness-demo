# Momentum Fitness — Demo Website

**This is a demo website only.** "Momentum Fitness" is a fictional business created to
showcase web design and development work. It is not a real gym and is not affiliated
with any real business of the same or similar name.

Built with plain HTML, CSS, and JavaScript — no frameworks.

## Pages

- `index.html` — Home
- `about.html` — About
- `services.html` — Services / membership plans
- `contact.html` — Contact, with a form

## Running locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.
